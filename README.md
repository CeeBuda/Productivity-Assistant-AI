# SBU Smart Assistant

Create an AI-Powered Workplace Productivity assistant.

The following features:

1.      Smart Email Generator

• Generate context-based professional emails

• Support tone variations (formal, informal, persuasive)

• Adapt content based on audience (client, manager, team)

2.      Meeting Notes Summarizer

 • Convert lengthy notes into concise summaries

• Extract key points, decisions, and action items

 • Highlight deadlines and responsibilities

3.      AI Task Planner / Scheduler

• Generate structured daily or weekly plans

• Prioritize tasks based on urgency and importance

• Suggest time optimization strategies

Name the assistant SBU Productivity Assistant

The repository the assistant must be saved in on GitHub should be named Productivity-Assistant- AI

The AI must be:

Responsive on desktop, tablet, and mobile devices

Professional and modern UI/UX

Easy navigation

Deployed online using GitHub Pages
